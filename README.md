# Ход кода

Браузерные шахматы для Azyon Incubator 2026. Фишка — необязательный редактор ChessScript: фигура делает ход, написанный игроком, по тем же правилам, что и при клике на доску.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm install
npm run dev
npm test
npm run build
```

Готовый статический сайт находится в `dist/`. Его можно опубликовать на любом статическом хостинге. Для запуска приложения нужен HTTP-сервер, открывать index.html через file:// не следует.

## Возможности

- Все легальные ходы, обе рокировки, взятие на проходе, выбор четырёх фигур при превращении.
- Шах, мат, пат; автоматическая ничья при трёхкратном повторении, недостатке материала и по правилу 50 ходов.
- Два человека за одним устройством либо игра белыми против любительского бота с поиском на 2 полухода.
- Подсветка ходов, отмена, переворот доски, звук, история, экспорт PGN.
- Адаптивная мобильная версия, управление клетками с клавиатуры, сохранение партии в localStorage.
- Ходы через код отмечены значком `</>` в истории.

## ChessScript

Выбери фигуру на доске или в списке. Напиши:

```js
const target = "e4";
if (piece.canMove(target)) {
  piece.move(target);
}
```

Это ограниченный интерпретируемый язык с синтаксисом JavaScript: строки, const, if/else, комментарии //, piece.move и piece.canMove. Произвольный JavaScript не выполняется: нет eval, Function, доступа к DOM, сети и циклов. Весь код разбирается и проверяется до хода. Один запуск может сделать только один ход. Кнопка «Проверить» не меняет игру. Если ветка не выполняет ход, позиция остаётся прежней.

Превращение: `piece.move("e8", "n")`, где q/r/b/n — ферзь/ладья/слон/конь. Если параметр не указан, показывается окно выбора. Рокировка задаётся конечной клеткой короля.

## Сценарий видео до 2 минут

1. 0:00–0:15: показать два режима и сказать: «В Ходе кода можно играть как обычно или программировать ход выбранной фигуры».
2. 0:15–0:35: режим «Вдвоём», пешка f2 → f3 кликом. Выбрать пешку e7, ввести `piece.move("e5");`, нажать «Проверить», затем «Сделать ход».
3. 0:35–0:55: выбрать пешку g2, ввести невозможный `piece.move("g5");` и показать ошибку. Исправить на `piece.move("g4");`, сделать ход.
4. 0:55–1:15: выбрать ферзя d8, написать `piece.move("h4");`, сделать ход. Мат чёрных отображается на доске.
5. 1:15–1:40: показать отметки кода в истории, справку с if/else и кнопку «Новая игра». По желанию продемонстрировать мобильный вид.

## Технологии

Vanilla JavaScript, Vite, chess.js (BSD-2-Clause), Lucide (ISC). Собственные SVG-фигуры. Бот работает в Web Worker. Шрифты Golos Text и IBM Plex Mono загружаются с Google Fonts; при отсутствии сети используются системные шрифты. Основная игра и иконки включены в сборку, CDN для логики не нужен.
